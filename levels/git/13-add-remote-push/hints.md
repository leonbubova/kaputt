## 1
A remote is a named URL/path: `git remote add <name> <path>`. `git remote -v` lists them.
## 2
`git remote add origin ~/.k8s-wargame/git/origin.git`. Then push the branch: `git push -u origin main` (`-u` remembers it for next time).
## 3
