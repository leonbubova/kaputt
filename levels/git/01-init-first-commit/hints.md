## 1
A directory becomes a repo with `git init`. Then `git status` shows the files as untracked.
## 2
Commits are made from the staging area: `git add <files>` first, then `git commit -m "..."`.
## 3
`git init && git add README.md app.py && git commit -m "Initial project"`. If git asks who you are: `git config user.name/user.email`.
