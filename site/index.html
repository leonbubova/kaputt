how it works

1

we break it

each level spins up a real environment — a Kubernetes cluster, a Postgres box, a running web app — then quietly introduces one realistic fault.

2

you get the ticket

a short incident report, the way a teammate would describe it. no hint of the cause. finding it is the job.

3

you fix it for real

you use kubectl, docker, psql, git — the real tools, in your own terminal. the game never wraps them.

4

it checks the outcome

wg check verifies the system works again — not how you got there. green means solved. then you repeat it until it's second nature.

how to play

# one-time setup — installs docker, k3d, kubectl, helm
./install.sh

# pick a discipline, bring it up, load a broken level
wg track k8s
wg start
wg level 1

# investigate with real tools, then judge yourself
kubectl get pods
wg check          # green = solved → wg next
wg hint           # stuck? 3 per level, counted
wg progress       # your scoreboard across every track

runs on a disposable environment on your own machine, mac or linux. every level resets clean, so you can redo it until it's muscle memory.
